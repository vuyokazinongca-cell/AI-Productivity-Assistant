# SimplyStyle AI Assistant

Create a professional AI-powered business assistant called SimplyStyleByLerato for a beauty and wellness business offering massages, manicures, pedicures, acrylic nails, laundry pickup and delivery, and skincare products.

Requirements:

1. Dashboard Layout
- Modern beauty-themed dashboard
- Welcome section with business overview
- Quick access cards for all AI tools
- Statistics panel showing tasks, bookings, and activity

2. Sidebar Navigation
- Dashboard
- Smart Email Generator
- Meeting Notes Summarizer
- AI Task Planner
- AI Research Assistant
- AI Chatbot
- Settings

3. Responsive Design
- Mobile and desktop friendly
- Clean and professional layout
- Soft pink, gold, white, and beige color palette

4. Input & Output Sections
- Input text area for user requests
- Generate button
- Output display area for AI responses
- Copy and clear buttons

5. AI Features

Smart Email Generator
- Generate professional emails
- Support formal, friendly, and persuasive tones

Meeting Notes Summarizer
- Summarize long notes
- Extract action items, decisions, and deadlines

AI Task Planner / Scheduler
- Generate daily and weekly schedules
- Prioritize tasks effectively

AI Research Assistant
- Summarize topics and articles
- Provide insights and recommendations

AI Chatbot Interface
- Interactive workplace assistant
- Answer questions and assist users

6. Professional UI/UX
- Elegant beauty salon branding
- Modern cards and icons
- User-friendly navigation
- Fast and simple workflow

7. Responsible AI Disclaimer
- Display: “AI-generated content may contain inaccuracies. Please review all outputs before making business decisions.”

Generate a polished, professional, and fully responsive application prototype suitable for a beauty business.
